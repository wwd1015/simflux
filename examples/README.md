# Examples

The reference example scripts previously shipped with the project have
been superseded by the documentation:

- [User Guide](../docs/user_guide.md) – interactive walkthroughs for GBM,
  portfolio simulations, benchmarking, and fallback behaviour.
- [Performance Benchmarks](../docs/performance_benchmarks.md) – detailed
  Rust vs NumPy results and measurement methodology.

Copy the snippets from those guides into a notebook or Python shell to
recreate the workflows that used to live in this directory.
