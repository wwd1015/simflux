# SimFlux Examples

This directory contains runnable examples demonstrating SimFlux functionality.

## 🚀 Quick Start Examples

### Standalone Python Scripts
- **`basic_gbm_example.py`** - Single asset Geometric Brownian Motion simulation
- **`correlated_assets_example.py`** - Multi-asset correlated simulations
- **`portfolio_risk_example.py`** - Portfolio loss modeling and risk metrics

### Run Examples
```bash
# From project root
python examples/basic_gbm_example.py
python examples/correlated_assets_example.py
python examples/portfolio_risk_example.py

# Or using make targets
make example-gbm
make example-portfolio
```
